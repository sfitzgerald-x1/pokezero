# Offline privileged critic on the actual production B trunk

This is an implemented fitter, not a fit result or a game producer. Both entry
points are opt-in. No import initializes a model, samples a trajectory or trains.
The ordinary owner runs them only after the one producer review, using the
shared search GPU and the completed immutable truth bank.

## Genuine private rows

Run `gpu_engine/device_privileged_rows.py` as a FILE with `--original-source`,
`--config`, `--expected-config-sha256`, `--output` and `--enable-prepare`. Its
config is the original truth config plus digest-bound `truth_summary` and
`reconstructed_index`. The latter must be the index published beside the actual
completed truth file. No new team, model or sampler is required for preparation.

The original-source factory, namespace, source/pool/category and runtime guards
remain. Every root must match the original full physical/world digest, public
root digest and public29 literal tensors. A child is constructed only from that
same root with its original fixed reply/chance. Its public bytes or actual
terminal must match. Separate head-grid branches must match their saved tensors
with exact shape/dtype/bytes or actual terminal value. No neighboring state or
invented hidden latent is used. Root outcomes are the original collector's
outcomes, never alternate-child labels.

The source encoder supplies BOTH seats' genuine own-party tokens. The array
adapter implements the existing `v5_contract.privileged_view` swap: only numeric,
category and attention arrays at opponent positions7:13 are replaced with the
actual peer-own positions1:7. Original role IDs, public belief tails, actions,
field tokens and all remaining public bytes stay intact. Original physical IDs
and `Trackers.own_order` define the permutation. Known public encounter slots
are preserved; unseen slots are explicitly completed with unused genuine
physical party members in ascending physical order. This is **offline privilege**,
not a claim that unseen identities were public. It does not modify the public
carry/actor or publish a policy.

Unavailable/error/private rows remain metadata rows with no tensor index. They
are not zero-filled observations. The NPZ contains only actual available rows;
every array has one unique original row identity. Child targets exist only when
all64 original truth continuations have terminal outcomes. All missing roots,
children and grid branches remain in the evaluation denominator.

## Actual fit and checkpoint provenance

Run `python -m pokezero.v5_privileged_critic --config ...
--expected-config-sha256 ... --rows ... --expected-rows-sha256 ... --output ...
--enable-fit` in the **B checkpoint's compatible original training environment**.
Do not relax the original strict checkpoint/contract loader if incompatible.

Fit config references are `production_declaration`, `run_started_event`,
`checkpoint_event`, `checkpoint` and `truth_summary`. They are actual immutable
scientific data references(path/SHA256), not operational identity receipts.
The original declaration must name B and the full2M-game production plan.
Checkpoint publication must belong to that same original run and have positive
steps/rows, matching the actual checkpoint. A20k smoke or initial diagnostic
trunk does not qualify. The digest-verified checkpoint bytes are copied to a
private immutable snapshot consumed by the unchanged strict loader; the source
checkpoint remains untouched. Scheduled checkpoints also need the original
`learning_rate_window`. Category and label namespaces must match the rows.

`fit` declares seed2103700000, at most20epochs(default10), learning_rate<=1e-4
(default1e-5), batch_size(default256), device and explicit precision(defaultBF16). No hyperparameter sweep or test
selection is performed. Restore the actual B public value head/query—never a
new random/damaged head. Freeze every other parameter and buffer, keep the model
in eval mode throughout, and optimize only `value_head` and `value_query` with
new head-only AdamW, zero weight decay, MSE against complete64 rollout means,
gradient-norm bound1. Original B trunk/optimizer/RNG/checkpoint bytes are not
trained or rewritten; this is a separate offline critic optimization.

Five folds are predeclared by original game/stream, seed2103700000. All frames,
siblings, grid rows and64 continuations of one game share a fold. For test k,
validate on(k+1)%5 and fit only complete child rows in the other3folds. Root and
grid rows are NEVER fit targets. Epoch0 is the original public-head warmstart;
it is always eligible and wins ties. Select by validation MSE only. Test targets
are never given to training or selection. Every declared test row receives one
out-of-fold prediction or explicit unknown. Every fold restores the same B
checkpoint and a fresh head optimizer. Frozen state bytes must still match.

Output contains per-fold training counts, actual optimizer updates, validation
history, selected epoch and head-only artifact; every prediction names its test
fold. Missing train/validation is warmstart-only and `fit_complete` remains false.
The identical public/root/child/grid truth reducer supplies ECE, Brier, Spearman,
primary sibling gap and depth-one backup diagnostics, retaining unknowns. This
is a crossfit estimate; it is not the heldout score of one final critic fitted
on all bank games. The fit/evaluation uses the original Torch model with recorded precision; a
separately scored JAX public baseline may include framework rounding differences,
so that comparison alone is not an isolated conditioning-effect attribution.
No actor export, strength, readiness or automatic gate pass
is claimed. A final all-bank critic would need an independent evaluation set.

Actual required inputs are: completed immutable truth, verified full root/child
physical state, source-compatible original factory/runtime, actual trained B
production checkpoint and its original publication/declaration. Until these
exist no privileged fit result is available. No new games are needed or run.
All tensors/models/bulk outputs remain on remote storage at execution time.
