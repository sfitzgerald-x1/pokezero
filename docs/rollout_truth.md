# Fixed-bank rollout truth

This producer is source staging, not a measured value-head result. It extends
the original complete heldout declaration; it does not rerun its terminal games
or change its outcomes. The human brief's 988 observed slots and 8,378 children
are reported beside actual file counts. All 256 declared games, 1,024 selectors,
original refusals and all actual declared child branches remain in the output.

The original producer saved typed physical state for only its 40 cost roots.
Public observation tensors alone cannot supply unrecorded private state. The
quarantined reconstruction uses the original bank's clean source checkout,
original runtime, immutable pool, actual original actors, constructor/gender and
sampling declarations. It makes one prefix pass, stopping each row at its last
required observed selector (never after frame24). A root is accepted only if
full physical `world_id`, full-public `root_id` and literal public29 observation
ALL match. Mismatch or unavailability stays missing. There is no retry/tuning
loop or replacement of an original outcome.

Run the new producer FILE under the original bank environment, with explicit
opt-in. This avoids importing the new engine over the original source package:

```
python /new/source/gpu_engine/device_rollout_truth.py \
  --original-source /original/clean/source \
  --config /fresh/declared-truth-config.json \
  --expected-config-sha256 ACTUAL_CONFIG_DIGEST \
  --output /fresh/rollout-truth-output --enable-truth
```

The configuration contains digest-bound `declaration`, `positions`, `siblings`,
`root_index`, `runtime`, `prespec` and original9375 `raw_actor` archive references,
plus predeclared `seed`, positive `max_requests`, and `split_seed`. All references
are real scientific artifact bindings. No absent digest is replaced with a
placeholder. The original runtime's exact source/PATH/catalog/pool/memory checks
run before any reconstruction. The archive must identify the original9375
checkpoint. Both continuation seats use that one frozen raw policy with deterministic
legal argmax and lower-index ties; engine chance, not categorical policy
sampling, varies across the64 replicates. This is independent
of the head later evaluated. No training or outcome-conditioned selection runs.

Each original child receives exactly64 fresh continuation IDs. Keys bind seed,
original root address, own action, recorded reply/chance and replicate ordinal.
Every continuation call has exactly32 child slots×64=2,048 physical lanes.
Unavailable and tail children preserve their original slot positions; ignored
padding copies a verified physical state/public carry and is marked inactive.
Only actual child dispositions are returned. No padding becomes truth or refill.
If no verified physical root exists at all, all slots stay missing without
inventing a padding battle. The original engine/public step, encoder routing and BF16 raw
policy are used. Caps/view or engine refusals remain unknown returns. Full-target
means are absent until all64 finish; known outcomes give conservative bounds and
complete batches report Monte Carlo standard error. This truth is conditional
on the frozen raw policy and original recorded physical world, not minimax truth.

The original sibling set has only one recorded opponent reply. A separate,
predeclared **head-only** grid evaluates every legal own action against every
legal reply under the same original chance capsule and physical world. It adds
no rollout-truth children. Frozen9375 reply probabilities retain their entire
legal denominator. Any required unknown branch makes the backup unknown;
otherwise mean over replies, then max over own actions, gives the backup.
Its Brier comparison uses the original root's terminal outcome. This fixed-
chance, single-world diagnostic is not an expectation over all chance/worlds.

`device_rollout_truth_score.evaluate` loads each head through its original
verified archive loader, evaluates the SAME bank/truth/grid and never changes
rollout actions. Root calibration uses original ordinary outcomes under the original declared
collector actors (A0), not newly invented9375/evaluated-head outcomes. Child
continuation outcomes instead condition on frozen9375, a deliberate policy
difference retained in the interpretation. Child Brier
is the average squared error against the64 actual terminal win/draw/loss
returns, not squared error to their sample mean. Probability scale is[0,1].
ECE uses15 predeclared equal-width bins, Spearman uses average tie ranks, and the
top-two check selects truth's best two siblings only when their mean-value gap
is at least0.05 in expected-outcome[-1,1] units (0.025 on the win-probability
scale). A raw0.10/probability0.05 sensitivity is descriptive only, not a bar. Root/child missing counts and unknown groups remain explicit;
conditional metrics do not become a full-denominator pass. Bars are child
ECE<=0.03, Spearman>=0.6, top-two resolution>=0.6 and lower matched-root backup
Brier. Monte Carlo uncertainty and raw-policy/engine bias remain limitations.

## Later privileged critic, without new games

The first producer does **not** fit a critic or initialize another model. Once
truth exists and an actual B production checkpoint is bound, freeze its trunk
and warm-start the privileged head from its original public value head. The
manifest declares five game-clustered folds by a fixed seed before outcomes.
All frames, siblings and64 continuations of one game stay in one fold. For test
fold k, validate on(k+1)%5 and fit on the remaining three. Keep epoch0 eligible,
use small head-only updates and select only on validation. Every reported
critic prediction is out-of-fold. Do not reuse A2's damaged-head/epoch0-exclusion
procedure. A final critic fitted on all bank games has no honest heldout score
on those same games; report it separately from the crossfit estimate. Training
needs actual privileged rows and the bound B checkpoint; this source makes no
claim that those inputs or the fit already exist. A future genuine Foul Play
root extension stays separate from the unchanged original-bank denominator.

No GPU allocation, team generation or scientific execution occurs on import.
The owner dispatches only after the single producer review, sharing the already
allocated search GPU. All bulk snapshots, tensors, model files and results stay
on remote storage. No speed, parity, strength or gate pass follows from tests.
