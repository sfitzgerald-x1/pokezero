# Phase D bounded constructor batch 2

This source implements only owning PP carry, positively public item removals,
and both-side sleep clocks. It changes no engine, public tracker, shared device
world mapper, source sampler, or determinization. No measurement, coverage pass,
fidelity admission, search timing, or ladder admission follows from these tests.
The existing 200 frozen addresses, world identity schema and seed derivation
remain unchanged; 16 draws are the prefix of 32. No failed draw is replaced.

## Own PP

The full genuine owning prefix provides the latest active request's exact PP
for each member. Each later public primary move debits its declared cost until
a newer exact active packet replaces that arithmetic. Revealed effective
Pressure doubles a pressured move's cost; sampled opponent abilities never
supply PP evidence. Called moves and public locked charge releases do not debit
PP twice. PP-less Solar Beam/recharge/Struggle and forced replacement packets
retain an earlier exact snapshot, rather than inventing a new snapshot.
A complete start prefix proves full format maximum PP only for a never-active
member. Missing snapshots, ambiguous identity/move joins and publicly indicated
PP-changing effects without a later exact refresh remain named refusals.

After this exact carry exists, `own-request-mapper-disagreement:pp` remains a
reported invariant with literal mapped/carried coordinates and `fatal: false`.
Other own mapper disagreements retain their original fatal identities. The
returned detached root carries the same exact PP used by the physical world.
The public encoder input and persistent B2 carry are not modified.

## Removed items

Positive B2 `item_removed` evidence resolves only the matching
`item-state-removed:<species>` blocker. The original pure
`battle_spec_from_payload` already accepts `removed_item_species`; this Phase D
route supplies that argument while preserving the original public payload and
pre-removal shown item. Sampled opposing sets must first satisfy the original
public posterior, including their revealed original item, before their physical
held item is cleared. Trick, Thief and Covet mutation histories remain
`PUBLIC_ITEM_SWAP_NOT_SUPPORTED`; unrelated blockers remain fatal.

The frozen numerical `BattleState` has a held `item` field but no additional
consumed-item/recycle inventory. Its `monfeatures` and item helpers add no such
state. Public hooks retain revealed/removal carry; their `item_credit` entry is
explicitly deferred. Therefore this constructor writes only the existing
post-removal physical item state and preserves the existing public reveal and
removal state. It does not create a consumed-item field or claim support for
unrepresented item-credit mechanics.

## Sleep

Only literal `slp` is deferred in a value copy of the typed bridge payload.
The original mapper continues to reject other unsupported statuses. Before a
world is returned or its carry/encoder/legal surface can be used, every sleeping
member on either seat must have its status, positive remaining counter, Rest
origin, and skipped/refund counter restored. No partially restored world can
escape. The nonprotocol `from_b2` default continues to refuse own latent sleep;
only the genuine protocol route explicitly opts into this restoration.

A public infliction stint, species/slot join and agreement with B2's count,
Rest, skipped and pending evidence are required. Rest begins at 3; induced
sleep begins uniformly on 2..5. Each public sleep attempt consumes one unit,
or two when that attempt's effective ability is Early Bird. Public ability
overrides are retained per attempt; otherwise the owning/sampled world's
original ability supplies its hypothetical rate. A proven sleep-usable attempt
carries one skipped unit; actual reentry refunds one unit, including under
Early Bird. Full attempt/refund chronology conditions the posterior on every
observed survived attempt, so a later refund cannot restore a duration that
would already have woken. In ordinary no-refund constant-ability histories this
reduces to the declared remaining-count support. Unsettled or inconsistent
histories refuse with their specific public-evidence kind.

Rest's surviving support is deterministic. A multi-value induced support is
sampled uniformly with the existing kernel-seeded world RNG, after the unchanged
public foe HP draws. The diagnostic records support and draw. This is a hidden
clock support assertion, not exact equality to an unavailable hidden native
clock. Exact known-own request facts, hidden clock support, native state
comparison and transition agreement are distinct validations. The old 200
captures lack recorded true-opponent/native state; any unavailable oracle
validation must remain UNKNOWN, without a source fallback or synthetic truth.

## Current-source collect-all interface

`phase_d_guard_diagnostic.scan(adapter, request, public, source, metadata,
*, lines, checks=None)` consumes an original folded `JaxRecordedAdapter`, parsed
own packet, genuine `PublicRoot`, and the original compiled public `Source`.
It returns `checks`, `all_refusals`, `not_evaluable`, and `coverage_claim: false`.
It retains the actual `from_b2` refusal and independently evaluable raw guards.
When a detached root exists it calls the shared
`phase_d_protocol_world.diagnostic_inputs(public, detached, *, lines, metadata)`
for current exact PP, item-resolution and preflight predicates. No sampled
surrogate or repaired input is created by this scan.

Each production `ProtocolWorld` has optional `mapper_diagnostics`; the sampled
`WorldSet.mapper_diagnostics` is an ordered tuple of
`{world: index, checks: [...]}`. Every check has `kind`, `status`
(`CLEAR`, `TRIGGERED`, or `NOT_EVALUABLE`) and, for production/shared input
checks, `fatal`. Legacy raw rows without `fatal` are fatal by default.
Nonfatal triggered PP is a receipt. Combine the raw scan, actual world refusals,
and these production diagnostics; an absent row never means CLEAR.

Independent own fields, public foe HP/PP/toxic/protect checks, and each sleep
member retain their evidence when another evaluable check fails. No exact-own
field mismatch is silently overwritten into admission. Named downstream groups
(`OWN_MAPPER_FIELDS`, `PUBLIC_FOE_SLOT_CARRIES`,
`PUBLIC_SLEEP_WORLD_POSTERIOR`, `FINAL_PUBLIC_CARRY`) remain NOT_EVALUABLE when
an earlier prerequisite prevents their evaluation. Their explicit reason must
survive aggregation. No collector result itself admits a world.

The root-owned driver must preserve all 200 denominator rows at both 16/32,
original world/kernel keys, per-band refusal overlaps, receipts and unknowns.
The bounded coverage gate is 80% overall and 65% in every band; a miss stops
with the table and diagnosis handoff. Ladder admission separately needs 85%
and 75%. The earlier 83% count is a diagnostic upper bound on triggered guards,
not an expected or demonstrated coverage result. Replacement requests,
Substitute, Wish, Flash Fire, species mismatch and other tail mechanics remain
outside this batch. One combined producer review must precede the one declared
remeasurement.
