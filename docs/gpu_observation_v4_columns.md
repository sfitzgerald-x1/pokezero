# GPU v4 observation column port plan

Each row names one physical v4 tensor column. Numeric constants are private writer indices; `v4_numeric_index` defines their physical projection. Source links name the Python writers, including helpers that write indexed buckets. Zero and padding remain the default for rows where a writer does not apply. This is an implementation plan; column parity is measured at the protocol gate.
