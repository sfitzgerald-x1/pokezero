# Configured owning-path offline cost

This source implements the objective's existing section 6 rule: at least 20
saved roots, nearest-rank p95 no greater than half the configured learner
decision limit. It launches no games. Source tests are not measurements or B3
qualification. Actual execution follows B2 admission, integrated controls and
independent scientific source review; no numerical learner limit is supplied
by this producer.

`scripts/owning_encoder_cost.py prepare --input INPUT --out PRESPEC` accepts
`study_prespec`, `selection` and `selection_metadata` as `{path, sha256}`
references, `collection` as the remote corrected-A2 collection directory and
`source_commit` as the exact clean producer commit. The study must be the v2
prespec with explicit positive `owning_decision_timeout_seconds`, identical
control value, `owning_public_single_line=true`, and the exact reviewed
`execution.public_dispatch=one_literal_line_per_call_terminal_suffix_atomic`.
The cost prespec binds that same descriptor. The atomic terminal suffix
exception does not affect these selected actionable, preterminal roots.
Component timeouts such as
FoulPlay's 1000 ms or the owner terminal timeout cannot substitute. Missing
merged runtime fields refuse before loading the model.

Preparation verifies the original producer/cohort/collection and B2 first-256
TRAIN selection metadata. It parses boundary addresses and requested seats
without deserializing tensor/action/outcome values. Candidate metadata hashes
deterministically rank addresses; greedy selection takes 20 distinct battles
with ten requested roots per seat. Selected own-prefix, delta and request
identities are bound only after that selection is final. Malformed or missing
chosen roots refuse; they are never replaced. No teacher bank or native R7
reconstruction is used. Source bytes and commit are bound, and execution
recomputes the derivation before model setup.

`run --prespec PRESPEC --prespec-sha256 SHA --out NEW_DIRECTORY` fsyncs the new
directory's parent, full prespec and all 20 planned ledger rows before runtime
setup. It validates the existing actual-owning 173-column/FP32 B2 admission and
review. One ordinary champion model, factory and immutable catalog are used
per attempt. Every root gets fresh actor, provider leases, device/host state
and policy history. The exact champion contract requires zero transition
tokens, window size one and mean aggregation; prior policy choices are not
invented or replayed.

Setup/model load, each fresh actor/catalog allocation and strictly earlier
owner-prefix priming have separate timings. There is no warmup or excluded
selected sample. The selected timer starts before ingestion of that saved
owner delta, one literal per call, and ends after the existing
`OwningWireSession.boundary` request-cache/ready-role guard and owning snapshot,
real 132-numeric/41-categorical JAX encoding, ordinary FP32 RawPolicy selection
and choice extraction. The first selected encode/JIT cost remains in the
sample. Any first-use JIT during earlier-prefix priming remains disclosed in
that priming time; no claim is made that these separate components isolate
compiler CPU time. The timer includes selected literal ingestion, making its
scope wider than the live candidate's boundary-guard-to-choice deadline.

The exact captured latest request strings for both seats and requested-player
list are bound after metadata selection. The peer request is used only by the
same host guard as the live bridge; it never enters the owning actor, backend,
JAX state, or owner context. One unchanged factory supports both owners under
its existing axis/model/catalog contract. Each root uses the real session
constructor with a fresh registration config copying all controls and changing
only its saved seat/seed and one-root registration count. No factory identity
guard is bypassed. Fresh actors may each register stream 1 in separate state.

This matches the prospectively configured single-line ingestion geometry.
Historical transport chunk boundaries were not captured; these results cannot
describe those chunks. The cost attempt produces no submitted choice and
closes each selected nonterminal actor as `ABORTED_UNQUALIFIED`.

The reducer uses rank 19 of exactly 20 valid decisions, also reports the
maximum, the explicit limit and limit/2. Every selected sample is retained,
including slow/cold ones. Exceptions stop the attempt with a failed-unknown
root and remaining roots not attempted; setup failures leave all roots unknown.
Each root is durably marked `ATTEMPTING_UNKNOWN` before it starts, so a hard
interruption cannot label an already started root as not attempted.
No retries, resume, redraw or refill exist. Fewer than 20 valid roots cannot
satisfy the rule. A completed numeric readout still requires independent
scientific results review and does not qualify B3 automatically.

A `VALID` label alone is insufficient. Both producer and reducer require the
actual actor registration context and full clean `ABORTED_UNQUALIFIED` closure,
matching the fixed battle, owner, namespace, seed, stream, prefix, generation,
line count and request count. Terminal/error/qualification claims cannot replace
that evidence. Setup, actor/catalog, prior priming and selected attempt/completed
timings must be finite and nonnegative; selected attempt and completed durations
must agree. Only a full normal ledger with a strict integer exit code zero and
no failure can satisfy the rule. Missing or modified evidence refuses reduction.
