# Class-(iii) tests: their SUBJECT is the default's identity, so rotating the default MUST
# break them. This file is the drill's pass condition -- the breakage set must equal it exactly.
#
# A test belongs here only if it asserts *which schema is currently default* -- AND NOTHING ELSE.
# Two entries used to also assert tuples the drill mutates (SUPPORTED, FEATURE_PACK), so they
# broke on the mutation whether or not their default assertion bound, and the
# EXPECTED-BUT-DID-NOT-BREAK detector -- the only guard against a pin silently going stale -- could
# never fire for them. Both were split; a row here must be a single-assertion identity pin. A test that
# merely uses the default is NOT class (iii); it is an unmigrated site and belongs in the
# ledger instead. Keeping that line sharp is the whole point: this file is the one place the
# migration could be silently declared finished by relabelling failures as expected.
